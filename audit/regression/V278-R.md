# V278-R | تفکیک نماهای نصب‌کننده و SQL

مبنا: f8b8424889b0e8e01c14b2797d7c3a0a6744a160 (V277-R).

در دو UserControl جدید، کنترل‌ها و چیدمان نصب‌کننده و SQL از منطق View جدا شدند. مسیرهای دسترسی، اعتبارسنجی، ترتیب عملیات و وضعیت اتصال موجود در Presenter باقی ماندند. مدل پیشنهادی رمز/ذخیره آن تغییر نکرد و هیچ عملیات یا سیاست SQL جدیدی اضافه نشده است.

پذیرش مالک (اجرا نشده): فهرست کارت‌های نصب، انتخاب cache، گزینه موجود/نصب SQL، اسکرول و بازسازی پنل، حفاظت نمایش رمز و برگشت از مرحله بدون اقدامات نصب یا SQL واقعی.

آزمون، کامپایل، Build، Runtime، Deploy و CI اجرا نشد. پذیرش ویندوز بر عهده مالک است.

گام بعد: کاتالوگ مرکزی مراحل و مدیریت چرخه ناوبری برای A02.
