# R11 | پالایش خواندن تاریخچهٔ قدیمی

ضبط جدید قبل از نوشتن متن حساس را پالایش می‌کند، اما مدل خواندنی برای ورودی قدیمی می‌توانست متن خام نشان دهد. پالایش فقط روی فیلدهای متن آزاد مدل خواندنی اعمال می‌شود؛ شناسه، زمان، Result و BuildMode شناخته‌شده و اندازه‌ها محفوظ‌اند. sidecar و صفحهٔ بیننده بازسازی‌شدنی‌اند و هیچ خط تاریخچهٔ اصلی توسط مسیر خواندن بازنویسی نمی‌شود.

سناریوی بازخوانی مصنوعی با token و تطبیق بایت‌های منبع اضافه شد؛ اجرا: `NOT_RUN`.
