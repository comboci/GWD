# GWD V274-R | A02.3 — جداسازی صفحهٔ محل استقرار

مبنا: V273-R / bac5514e41dfab8a9b2c92bc245ba870a8e1b5b0. A02 همچنان باز است.

- صفحهٔ Deployment Location به UserControl مستقل منتقل شد. View انتخاب نهایی را اعلام می‌کند؛ پوسته همچنان تنها مالک پروفایل، نوشتن تنظیمات و آماده‌بودن ناوبری است.
- تغییر Default IIS چند کنترل را یکجا هماهنگ می‌کند و انتخاب میانی منتشر نمی‌شود. انتخاب پوشهٔ سفارشی پیش از Default و بازگشت به آن، Single Folder/Versioned، پاکسازی و محافظ پورت ۸۰ حفظ شده‌اند. سرویس IIS، موتور استقرار یا حذف اطلاعات تغییر نکرد.
- چهار سازندهٔ چینش مشترک به UI/Controls منتقل شدند؛ سایر صفحه‌ها همان پیاده‌سازی قبلی را فرا می‌خوانند. هنگام teardown، اشتراک صفحه قطع می‌شود. نتیجهٔ Browse بعد از غیرفعال‌شدن View اعمال نمی‌شود.
- این اصلاح بخشی از A02 است؛ صف تنظیمات هنوز به A03 موکول است. Build، اسکریپت‌های تست و Windows Runtime مطابق POLICY اجرا نشده‌اند. ادغام، انتشار EXE و استقرار انجام نشدند.

## پذیرش Windows VM توسط مالک
حالت محل اختصاصی را با ردیف ساختگی تست کنید؛ Default را فعال و دوباره غیرفعال کنید. مسیر اختصاصی، پورت ۸۰ هنگام Default، قفل مسیر و کنترل‌های Single/Versioned، نمایش Cleanup و حالت ذخیره‌شده پس از Back/Next بررسی شوند. بازگشت از Browse با Cancel نباید تنظیم را تغییر دهد. مسیر طولانی و DPI ۱۰۰ و ۲۰۰ درصد را نیز از نظر دسترسی به کنترل‌ها بررسی کنید. هیچ IIS عملیاتی یا اطلاعات حقیقی استفاده نشود.
