## نقص ایستای قابل‌اثبات — P1

`CommandRunner` رویداد stdout/stderr را از Threadهای غیراصلی گزارش می‌کند. در نسخهٔ V246، `WizardForm.AppendLog` برای Thread پس‌زمینه پیش از نوشتن فایل، `BeginInvoke` می‌کرد؛ ثبت شواهد روی دیسک به صف UI وابسته بود. در UI نیز هر خط یک `File.AppendAllText` مستقل، یک `_log.AppendText`، کنترل اندازهٔ TextBox، و احتمالاً ذخیرهٔ JSON انجام می‌داد. کندی UI در خروجی پرتعداد نتیجهٔ قابل انتظار این معماری است، ولی اندازه‌گیری واقعی نشده است.

## تغییر ایمن V247

1. `LogService.Write` همچنان پس از Redact و تحت قفل ترتیبیِ Session، پیام را **همان لحظه روی دیسک** ثبت می‌کند؛ `StreamWriter` و `FileStream` یک بار به‌ازای هر Session باز می‌شوند. `AutoFlush=true` هر خط را قبل از صف نمایش به OS تحویل می‌دهد. این وعدهٔ `fsync` در مقابل قطع برق نیست.
2. `Write(message, onPersisted)` callback کوتاه enqueue را **درون همان قفل** و پس از `WriteLine` اجرا می‌کند، بنابراین ترتیب enqueue با ترتیب نوشتن در همان Session همخوان است. رویداد قبلی `LineWritten` خارج از قفل باقی می‌ماند.
3. `WizardForm.AppendLog` دیگر برای هر خط `BeginInvoke` فراخوانی نمی‌کند. صف UI با سقف ۸۱۹۲ خط و `Timer` صد میلی‌ثانیه‌ای، حداکثر ۵۱۲ پیام را در یک batch به `TextBox` اضافه می‌کند.
4. در صورت ازدحام شدید فقط قدیمی‌ترین **پیام‌های نمایشی UI** حذف و اعلان واضح اضافه می‌شود. هیچ پیام دیسکی حذف یا به‌تعویق نمی‌افتد. حافظهٔ نمایش آخرین ۵۰۰۰ خط و سقف ۳۰۰هزار کاراکتر همچنان حفظ می‌شود.
5. `ResetWizard` فقط صف UI را تخلیه می‌کند. هنگام `StartNewSession`، Writer قبلی Flush/Dispose شده و سپس مسیر Session جدید منتشر می‌شود. در `FormClosing` Timer UI متوقف و `CloseSession` هندل فایل بسته می‌شود؛ callback دیرهنگام در صورت نیاز همان فایل را دوباره باز می‌کند تا شواهد دیسکی حفظ شود و UI بسته را لمس نمی‌کند.
6. `RenderVisibleLog` ابتدا pending را دریافت می‌کند؛ سپس فیلتر Minimal/Normal/Verbose را از داده‌های موجود بازسازی می‌کند.
7. افزایش `Directory.Build.props` از `246.0.0` به `247.0.0`.

## محدودیت‌ها و سناریوهای پذیرش

- ساختار Session و مکان فایل با نسخهٔ قبل سازگار است؛ نگهداشت Writer باز ممکن است حذف یا rename دستی فایل Session فعال را تا خروج برنامه مسدود کند. خواندن هم‌زمان با `FileShare.Read` مجاز است.
