# V284-R | پایش سلامت تک‌پرواز با ورودی ثابت و وضعیت واقعی

مبنا: 89a88ee3fff956e008b5d03b60410f58552211ee (V283-R).

پایش زمان‌بندی داخلی و درخواست دستی از یک کار مشترک استفاده می‌کنند. Profile زنده در Thread پس‌زمینه خوانده نمی‌شود؛ تغییر تنظیمات نمونهٔ قبلی را لغو و نسل جدید را آماده می‌کند. نتیجه و Callback قدیمی نمی‌توانند برچسب‌های مرحله جدید را بازنویسی کنند. IIS/HTTP محلی، SQL اداری و سلامت کل زمان جدا دارند؛ بررسی loopback هرگز وضعیت هدف Remote یا استقرار/بازیابی را تأیید نمی‌کند. نشست SQL در پایش از نتیجهٔ اجرایی جداست و مهیایی عملیاتی همچنان توسط چک قبلی همان عملیات تعیین می‌شود. عملیات Stop زمان‌بند و کار مشترک را لغو می‌کند و آزادسازی HTTP پس از خروج صورت می‌گیرد.

پذیرش مالک (اجرا نشده): درخواست‌های پیوسته، جابه‌جایی Host/SQL/Port، عدم بازنویسی نتیجه SQL دستی، پاسخ HTTP با redirect/failure، local/remote و توقف فرم در زمان بررسی.

آزمون، کامپایل، Build، Runtime، Deploy و CI اجرا نشد. پذیرش ویندوز بر عهده مالک است.

گام بعد: A09: DPI و چیدمان مرحله‌ها و صفحات پرریسک در اندازه کوچک.
