## U02 / U03 — اصلاح رابط

1. چهار Export ZIP، سه Action Code Quality و Cancel Export به `File → Export` با زیرمنوهای `Current Tab`، `All Diagnostics` و `Code Quality` منتقل شدند؛ همهٔ Handlerها همان متدهای موجود را فراخوانی می‌کنند.
2. `View → Refresh Selected Tab` جایگزین دکمهٔ Refresh در History و Code Quality شد و تنها در تبِ دارای Refresh و خارج از عملیات Export فعال است.
3. بخش بالایی فرم اکنون یک `MenuStrip` دسته‌بندی‌شده و یک Status Bar متنی است. کنترل‌های عملیاتی تکراری از Header و Code Quality حذف شدند؛ صفحات اصلی فقط نمایش، فیلتر، خلاصه، انتخاب و صفحه‌بندی را نگه داشتند.
4. دستهٔ Code Quality تنها زمانی فعال می‌شود که تب مربوط انتخاب شده و Build معتبری انتخاب شده باشد؛ `Refresh` در زمان خواندن async داده‌ها غیرفعال است. وضعیت Busy/Cancel مربوط به Export ZIP حفظ شده و در زمان Export، منوهای نامربوط غیرفعال‌اند.
5. نگاشت تب واقعی پس از Lazy Loading (V250) حفظ می‌شود؛ Contextual callbackها هنگام ساخته‌شدن TabPage ثبت و با Dispose آن حذف می‌شوند. هیچ کنترل Async Loader به تب موقت وابسته نشده است.
6. میان‌بر `Ctrl+Shift+E` برای Export تب فعلی و `Ctrl+R` برای Refresh تب انتخاب‌شده تعریف شد.
7. مسیر سرویس `DiagnosticBundleService`، محافظت فایل موقت، CancellationToken، Output path، Clipboard redaction و Export JSON/Markdown موجود دست‌نخورده‌اند.
