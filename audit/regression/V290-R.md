# GWD V290-R | مسیر پذیرش مالک

نسخهٔ سورس: `290.0.0` روی `fix/ui-performance-phase-01`، پایهٔ دقیق V289-R: `55dfad1ef8e3cdabd31be71d6903bcbad20b64d7`. وضعیت: **SOURCE_COMPLETE / RUNTIME_PENDING**. این یک نسخهٔ سورس است، نه Build یا انتشار اجرایی. شناسهٔ نهایی همان commit حاوی این مستند است.

مالک می‌تواند در checkout تمیز و جداگانه ابتدا تطبیق سورس و سپس، فقط در ماشین و حساب تست دورریختنی Windows، Build و Smoke را جداگانه اجرا کند:

```powershell
.\tests\run-v290-r-review.ps1 -ExpectedCommit '<exact GitHub commit SHA>' -RunSource
.\tests\run-v290-r-review.ps1 -ExpectedCommit '<exact GitHub commit SHA>' -RunWindowsSmoke -ConfirmDisposableVm
```

به پوشهٔ استقرار، IIS واقعی، SQL سازمان، تنظیمات واقعی یا رمز معتبر وصل نشوید. Runner شاخه یا انتشار را تغییر نمی‌دهد؛ برخی آزمون‌های Windows قدیمی سرویس‌ها و HKCU محلی را لمس می‌کنند و فقط برای محیط موقت مناسب‌اند. عبور از Smoke جایگزین سناریوهای دستی زیر و آزمون مستقل بازیابی نیست. هر شکست را با SHA، نسخهٔ Windows/.NET، گام و خروجی پالایش‌شده ثبت کنید.
