# R04 | تنظیمات معیوب، نوشتن اتمی و حفاظت اطلاعات ورود

خواندن فایل تنظیمات معیوب یا غیرقابل‌دسترس به وضعیت فقط‌خواندنی منجر می‌شود و فایل موجود در شروع کار بازنویسی نمی‌شود. بازیابی صریح فقط برای خرابی شناخته‌شده ممکن است؛ جایگزینی با نسخهٔ پشتیبان و در همان پوشه انجام می‌شود. ذخیرهٔ JSON از فایل موقت تخلیه‌شده، جایگزینی اتمی و مقایسهٔ بازبینی استفاده می‌کند. صف نوشتن محدود و مرتب است و بستن پنجره منتظر تخلیهٔ کنترل‌شده می‌ماند. حفاظت نسل اعتبارنامه، رمزگذاری Windows و پاک‌سازی بافرهای موقت باقی مانده‌اند.

همه‌چیزِ Registry چندمقداری تراکنش اتمی سراسری نیست؛ کنترل هم‌زمانی فرایند و تشخیص تغییر پایه جایگزین ادعای تراکنش سراسری است. تمام سناریوهای Windows، ازجمله DPAPI، `NOT_RUN` هستند.
